# Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, JavaScript, and Node.js to showcase my skills, education, projects, and contact information.

## Features

* Responsive design
* About, Education, Skills, and Projects sections
* Contact form with backend integration
* Simple and clean UI

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js

## Project Structure

```bash
portfolio-project/
│
├── index.html
├── server.js
├── package.json
└── node_modules/
```

## Installation

1. Clone the repository

```bash
git clone <repository-link>
```

2. Install dependencies

```bash
npm install
```

3. Run the server

```bash
node server.js
```

4. Open `index.html` in browser or use Live Server.

## Backend

The backend is created using Express.js and handles contact form submissions.
